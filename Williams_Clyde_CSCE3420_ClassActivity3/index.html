About the project

Semantic HTML gives each region a meaningful role that browsers, assistive technology, and people can understand.

This project uses clear structure and accessible choices before visual styling is added.

Coursework

The activity moves from HTML foundations to navigation, accessibility, and validation.

Start with meaning

Choose elements for the role their content plays. A section groups related ideas, while an article can stand on its own.

Accessibility reminder

Useful labels, headings, and alternative text make the same content easier to navigate.

Topics

  • Semantic landmarks and headings
  • Images and alternative text
  • Relative and external links
  • Forms, tables, and validation

Workflow

  1. Plan the document structure.
  2. Write the HTML5 foundation.
  3. Add links, media, lists, tables, and forms.
  4. Inspect, debug, and validate the page.
