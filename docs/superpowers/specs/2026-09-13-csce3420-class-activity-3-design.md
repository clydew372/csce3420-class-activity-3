# CSCE 3420 Class Activity 3 Completion Design

## Goal

## Project

- `debug.html` with the supplied distinct markup errors corrected.
- `profile.html` with an independently organized semantic profile page.

Evidence commands will show project structure, semantic source, headings, navigation, image and alt text, table, form, DOM-relevant nesting, corrected debug source, validation, Git history, remote contents, and the independent profile source.
